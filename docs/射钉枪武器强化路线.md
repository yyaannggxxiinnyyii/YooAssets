# 射钉枪武器强化路线草案

本文记录射钉枪的专属强化方向。当前目标是先做“风格选择 + 分支强化”的设计储备，实际游戏内仍可以先接入单个词条验证手感。

## 基础定位

- 武器名：射钉枪
- 基础定位：均衡步枪，弹夹、射速、伤害都偏稳定。
- 强化目标：不要只做数值堆叠，优先让每条路线改变玩法节奏、技能使用方式或子弹行为。

## 风格级强化

### 黑白双煞

- 额外获得一把射钉枪。
- 当前攻击力加成减半，作为双持带来的强正向收益的负面约束。
- 后续分支可以围绕左右枪不同属性、交替开火、双枪技能联动展开。

### 忠诚 III

- 弹夹不改，普通射击不改。
- 大技能取消。
- 小技能替换为“回收钉子”。
- 普通射钉命中或飞行结束后留下可回收钉子。
- 释放小技能时召回场上的钉子，钉子飞回玩家并对路径上的敌人造成一次伤害。
- 首版建议：召回伤害为当前攻击力 45%，单枚钉子对同一敌人最多命中一次，召回击杀不恢复技能能量。

### 排钉供能

- 倾向作为能量循环分支。
- 如果基础规则保持“击杀恢复能量”，该强化可以增加“普通子弹命中恢复少量能量”。
- 如果基础规则改为“命中恢复能量”，该强化可以改成“击杀额外恢复能量”。
- 后续需要和技能击杀回能规则一起定稿，避免能量循环过快。

## 技能联动强化

### 气动回填

- 释放武器技能后，立刻补满当前弹夹。
- 如果弹夹已经是满的，则获得 50% 弹夹容量的临时溢出弹药，打完后消失。
- 该效果本身不需要负面，因为它受技能能量消耗限制。

### 追踪弹头

- 释放武器技能后，接下来 4 秒普通射钉获得追踪。
- 强追踪版本：直接锁定子弹半径范围内最近敌人。
- 轻追踪版本：只轻微修正弹道，保留瞄准和走位价值。

### 空匣爆钉

- 弹夹打空时触发一次近距离爆钉或扇形散射。
- 可以与气动回填形成节奏联动：先打空触发爆钉，再用技能回填继续输出。
- 需要限制触发频率，避免高射速或小弹夹时过强。

## 子弹行为强化

### 钉头分裂

- 命中敌人后产生派生弹。
- 版本一：向随机方向发射两枚派生弹。
- 版本二：向附近另一个敌人弹出一枚派生弹。
- 派生弹建议不再触发分裂，避免指数级扩散。

### 回收钉雨

- 偏主动爆发型的回收玩法。
- 可以让场上钉子在召回前先短暂向外扩散，再统一回收，形成双段路径伤害。
- 也可以作为忠诚 III 分支下的后续强化，而不是独立风格。

### 钉墙封锁

- 普通射钉命中墙体或到达终点后短暂形成障碍/减速带。
- 更适合作为控制分支，强调走位和封路。
- 需要谨慎处理寻路与碰撞，首版可以只做减速区域。

### 铆接弱点

- 连续命中同一敌人会叠加“铆接”标记。
- 达到层数后下一次技能或召回伤害额外提高。
- 适合与忠诚 III、追踪弹头联动，强化对精英和 Boss 的持续输出。

## 数值待定

- 风格级强化通常应带来明显机制变化，强度过高时用攻击力、射速、能量消耗或触发条件做约束。
- 分支强化可以更偏数值和联动，但应尽量服务对应风格，不要变成通用属性池。
